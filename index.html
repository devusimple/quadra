QR code questions, answered

Are my QR codes private?

Yes. Quadra generates every QR code locally in your browser. Nothing you type is uploaded or stored anywhere.

What can I put in a QR code?

Website links, plain text, Wi-Fi network credentials, email addresses with subject and message, and phone numbers.

Will my QR code still scan if I change its colors?

It scans as long as there is strong contrast — a dark code on a light background works best. Quadra warns you about low-contrast or inverted color combinations that some scanners cannot read.

Should I download PNG or SVG?

Download PNG (512, 1024, or 2048 px) for screens, documents, and everyday printing. Download SVG for logos and professional print, because it scales to any size without losing sharpness.

What are error correction and the quiet margin?

Error correction (levels L, M, Q, H) lets a QR code still scan when it is scratched, dirty, or partly covered — higher levels make the pattern denser. The quiet margin is the blank border around the code that scanners need to detect it.
